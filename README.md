# Lumo AI

> Every major AI tool — one clean, ad-free app.

A free, privacy-first directory of the best AI tools on the web, organized by category. Tap any tool to preview it inside the app, then open it in your phone's secure in-app browser.

Built by [Lumo Labs](https://github.com/Frankimurgor) — a Kenyan studio crafting simple, beautiful mobile apps.

---

## ✨ Features

- **39 curated AI tools** across 7 categories (Chat, Image, Code, Video, Audio, Research, Productivity)
- 🔍 **Live search** by name, description, or category
- 🏷️ **Category filters** with horizontal chip navigation
- ⭐ **Favorites** — pin tools you use most, saved locally
- 🕒 **Recent history** — last 10 tools you opened
- 🌓 **Dark mode** — System / Light / Dark
- 🔀 **Sort options** — A–Z, by category, or favorites-first
- 📱 **In-app preview screens** — every tool gets a native preview before opening
- 🌐 **In-app browser** — opens tools in Chrome Custom Tabs / SafariViewController (no WebView, fully ToS-compliant)
- 🔒 **100% offline-first** — favorites, recents, and settings stored locally, no accounts, no backend

## 🛠️ Tech Stack

- **React Native + Expo SDK 57**
- **Expo Router** for file-based navigation
- **TypeScript** throughout
- **AsyncStorage** for local persistence
- **expo-web-browser** for the in-app browser
- **@expo-google-fonts** — Playfair Display (headings) + Inter (body)
